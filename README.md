# algoritmia

En este repositorio voy guardando los ejercicios que realizo en clase de Algoritmia utilizando PSeInt.

## Semana 1 - Introducción a los algoritmos

Practicar cómo crear algoritmos sencillos.

## Semana 2 - Lógica proposicional y decisiones

Realicé un algoritmo para saber si una persona puede entrar al cine dependiendo de su edad y si tiene entrada.
con su tabla de verdad y una prueba de escritorio para comprobar los resultados.

## Semana 3 - Ciclos y SubProcesos

Realicé un algoritmo de una factura de tienda donde se ingresan 3 productos y se calcula el total de la compra.
Utilicé el ciclo Para, un SubProceso, una tabla de traza y un árbol de componentes.
